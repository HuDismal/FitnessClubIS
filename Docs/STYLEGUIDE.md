# Руководство по стилю — ИС фитнес-клуба «Атлет»

## 1. Идея бренда
Спокойный, «здоровый» зелёный как основа и тёплый оранжевый акцент — энергия и движение.
Логотип — гантель, над грифом которой стоит буква «А» (Атлет).

## 2. Логотип и иконка
| Файл | Назначение |
|---|---|
| `Docs/brand/logo.svg`, `logo.png` (512×512) | логотип с названием: шапка меню, окно входа, документы |
| `Docs/brand/icon.svg`, `icon.ico` (16…256 px) | иконка приложения (свойство «Значок» проекта и окон) |

Охранное поле — не менее 1/8 ширины логотипа. Минимальный размер логотипа — 48×48 px.

## 3. Цвета
| Роль | HEX | Использование |
|---|---|---|
| Основной (Primary) | `#1B6B4A` | меню, кнопки, заголовки таблиц, заголовки страниц |
| Основной тёмный | `#134D35` | кнопка при наведении |
| Акцент (Accent) | `#F2A541` | выбранный пункт меню, выделения |
| Текст | `#1F2933` | основной текст |
| Приглушённый текст | `#6B7780` | подписи, подсказки |
| Поверхность | `#F4F7F5` | фон панелей, плиток, капчи |
| Опасность | `#C0392B` | удаление, ошибки |
| Фон окна | `#FFFFFF` | фон окон |

Соотношение контраста белого текста на `#1B6B4A` — 6,4:1 (проходит WCAG AA).

## 4. Типографика
* Шрифт интерфейса: **Segoe UI** (входит в состав Windows).
* Размеры: основной текст — 14 pt; подписи — 12 pt; заголовок страницы — 22 pt, SemiBold; заголовок окна входа — 22 pt.
* Капча — Consolas 26 pt, курсив, зачёркнутый.

## 5. Элементы управления
* **Кнопка**: высота 36, скругление 8, фон Primary, белый текст; наведение — Primary dark; отключена — прозрачность 45 %. Деструктивные действия — кнопка цвета «Опасность».
* **Поля ввода**: высота 34, внутренний отступ 8, граница `#B8C4BE`.
* **Таблица (DataGrid)**: заголовки Primary с белым полужирным текстом, только горизонтальные линии, высота строки 34.
* **Карточка**: белая, скругление 12, граница `#D5DED9`; при наведении — тень цвета Primary.
* **Диалоговые окна**: скруглённая карточка с тенью, иконка, заголовок, текст, панель кнопок (Info/Warning/Error — «OK», Question — «Да»/«Нет»).

## 6. Макет главного окна
Левая колонка 220 px: логотип и название, панель навигации (список разделов зависит от роли), внизу — профиль пользователя (аватар 44×44, ФИО, роль) и кнопка выхода. Справа — рабочая область (Frame со страницами).

## 7. Тексты
Обращение на «вы», короткие глаголы в кнопках («Добавить», «Изменить», «Удалить»), даты — `дд.мм.гггг`, суммы — `12 345,00 ₽`.
